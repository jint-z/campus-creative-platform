# 第一周验收记录

## 账号与权限自测

2026 年 11 月 21 日，在 Windows、JDK 21、项目独立 MySQL 8.4.13 和本地 Spring Boot 服务上验证本次认证 PR 的代码。

| 检查 | 结果 |
| --- | --- |
| 后端构建 | `mvn spotless:check verify` 通过，两项自动化测试覆盖令牌到期和退出后失效 |
| 学生账号 | 注册成功，大小写变体重复注册返回 409，格式超限返回 400，错误密码返回 401 |
| 注册角色 | 请求带 `role: ADMIN` 时，MySQL 和登录响应均显示 `STUDENT`，数据库保存 60 字符 BCrypt 哈希 |
| 管理员 | 本地初始化成功，可以登录后台账号接口。重启后仍使用原密码，学生和管理员不能使用对方的登录接口 |
| 业务路径权限 | 无令牌返回 401，学生请求后台路径及管理员请求学生路径返回 403。正确角色可到达路由层。学生与管理员均可通过媒体路径鉴权 |
| 会话与跨域 | 退出及服务重启后旧令牌返回 401。约定的后台来源可登录并通过带 Authorization 的预检。未配置来源的预检返回 403 |
| 基线探针 | `/api/dev/health` 与 `/api/dev/db` 均返回 200 和 `OK` |
