# Scope of Work · 第一周产品原型

> 校园创作分享平台｜v1.0
>
> 组长及验收负责人：余万鑫

## 1. 本周目标

交付一套可在本地运行的产品原型。学生在微信小程序注册、登录和发布作品，另一位学生能够浏览作品，管理员能在 Web 后台找到同一条作品并下架。周末以两条现场发布的作品验收，分别覆盖纯文字和带标签的单图图文。

开发沿用现有仓库的 uni-app 小程序、Vue Web 后台、Spring Boot 后端和 MySQL。基线已验证小程序模拟器、浏览器和数据库的联通。本周在同一后端和数据库上实现业务流程，演示环境为微信开发者工具模拟器和本地浏览器。[开发基线提交](https://github.com/jint-z/campus-creative-platform/commit/3690393bb36e3cb4b2a5dd3badf6271c4b17a128)

## 2. 功能范围

| 模块 | 本周交付 |
| --- | --- |
| 学生账号 | 小程序提供账号密码注册和登录。新注册账号为普通学生。提供切换到另一位学生账号的方式，便于在同一台电脑完成演示。 |
| 小程序发布 | 学生填写正文，发布纯文字作品或带一张实际上传图片的图文作品。可从预设标签中选填一个标签。发布成功后作品进入首页列表。 |
| 小程序浏览 | 已登录学生可以在首页看到已发布作品，打开详情查看作者、正文、图片和标签。 |
| 后台登录与查看 | 管理员使用预置账号登录。后台作品列表能定位刚发布的记录，详情可核对作者、正文、图片和标签。 |
| 后台下架 | 管理员可下架作品。下架状态写入数据库，小程序刷新后首页列表移除该作品，访问原详情时提示作品不可用。 |
| 数据与权限 | 后端存储账号、作品、标签、图片引用和作品状态，图片文件保存在演示环境中。后端校验发布者身份及后台操作权限，普通学生无法使用管理员功能。 |

短视频上传与播放、日期和标签筛选、评分评论、学生编辑和删除作品、完整个人中心、后台用户和评论管理，以及手机真机、远程部署和上架，安排到后续阶段。

## 4. 交付与验收

交付仓库 `main` 上的一份可运行版本，随版本提供业务数据库初始化脚本、预设标签与管理员账号的初始化方法、本地启动说明、接口说明和验收记录。验收记录写明提交号、环境、各项实际结果和待修问题。

| 编号 | 现场操作 | 通过标准 |
| --- | --- | --- |
| W1-01 | 按启动说明运行后端和 MySQL，在微信开发者工具打开小程序，在浏览器打开 Web 后台。 | 两端访问同一个本地后端，可进入各自的登录页面。 |
| W1-02 | 学生 A 注册并登录，先发布纯文字作品，再上传一张图片，选择一个预设标签并发布图文作品。 | 两次发布成功，首页出现两条新作品，图文详情可加载实际上传的图片。 |
| W1-03 | 切换到另一位学生 B 的账号，从首页分别打开两条作品。 | 学生 B 能读到学生 A 发布的两条作品，详情中的作者、正文、图片和标签与发布内容一致。 |
| W1-04 | 用预置管理员账号登录 Web 后台，在列表中找到图文作品并打开详情。 | 后台记录与小程序中的作者、正文、图片和标签一致。 |
| W1-05 | 管理员下架该图文作品，学生 B 刷新首页并尝试打开原详情。 | 纯文字作品仍然可见，图文作品从首页移除，原详情提示不可用。 |
| W1-06 | 使用学生 B 的身份尝试通过后台接口下架仍在展示的纯文字作品，再刷新小程序首页。 | 后端拒绝操作，纯文字作品仍然可见。 |

由余万鑫组织演示与验收。组员按上述步骤记录结果，通过后确认第一周原型交付。
